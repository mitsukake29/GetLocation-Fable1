# 🎲 ゲットリッチ・リバイバル

サービス終了した「LINE ゲットリッチ」へのオマージュとして作られた、ブラウザで遊べるすごろく型ボードゲームです。サイコロを振って世界の都市を買い占め、ライバルを破産に追い込みましょう！

> ※ 本作はファンメイドの非公式オマージュ作品です。LINE および原作ゲームの素材・キャラクターは一切使用していません。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要・依存ライブラリなし）。

```bash
# ローカルサーバーを立てる場合（任意）
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

1. キャラクター（🐻クマきち / 🐰ウサ姫 / 🐤ピヨ太 / 🐸ケロ蔵）と CPU の人数（1〜3人）を選んでスタート
2. 「サイコロを振る！」ボタンでサイコロを振り、盤面を時計回りに進みます
3. 全員 20,000G からスタート。**30ラウンド終了時に総資産1位**か、**他全員を破産**させれば優勝！

## ルール

### 都市マス（24都市）
- **購入**: 空き都市に止まると土地＋別荘🏠を購入できる
- **増築**: 自分の都市に止まると 別荘🏠 → ビル🏢 → ホテル🏨 → ランドマーク🗼 と増築できる（通行料アップ）
- **通行料**: 他人の都市に止まると通行料を支払う
- **買収**: 通行料を払った後、資産価値の2倍を払えばその都市を奪える（🗼ランドマークは買収不可！）
- **ライン独占**: 同じ色の都市3つを独占すると、そのラインの通行料が2倍

### 特殊マス
| マス | 効果 |
|---|---|
| 🏁 スタート | 通過で給料 3,000G、ぴったり止まるとボーナス +1,000G |
| 🎁 チャンス | カードを1枚引く（ボーナス、罰金、強制移動など全8種） |
| 🏝️ 無人島 | 2回休み。ゾロ目を出せば即脱出！ |
| 🔥 オリンピック | 自分の都市1つを開催地に指定し、通行料2倍（開催地は世界に1つ） |
| ✈️ 世界旅行 | 次のターン、好きなマスへ移動できる |
| 🏛️ 税務署 | 所持金の10%を納税 |

### その他
- ゾロ目を出すともう1回振れる（3連続はスピード違反で無人島行き！）
- 支払いができない場合は安い物件から強制売却され、それでも払えなければ**破産**
