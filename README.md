# 🎲 ゲットリッチ・リバイバル

サービス終了した「LINE ゲットリッチ」へのオマージュとして作られた、ブラウザで遊べるすごろく型ボードゲームです。サイコロを振って世界の都市を買い占め、ライバルを破産に追い込みましょう！

> ※ 本作はファンメイドの非公式オマージュ作品です。LINE および原作ゲームの素材・キャラクターは一切使用していません。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要・依存ライブラリなし）。

```bash
# ローカルサーバーを立てる場合（任意）
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

1. 日本の偉人キャラクター（能力つき・下表参照）と CPU の人数（1〜3人）を選んでスタート
2. **ゲージインパクト**：ゲージが左右に往復するので、タイミングよくボタンを押す。左側で止めると小さい目、右側で止めると大きい目が**出やすくなる**（確定ではない！）
3. 全員 5,000万 からスタート。**30ラウンド終了時に総資産1位**か、**他全員を破産**させれば優勝！

## ルール

### 都市マス（24都市）
建物は **別荘🏠 → ビル🏢 → ランドマーク🗼** の3段階。所有マスはプレイヤーカラーに染まります。

例：土地価格 P = 500万 の都市の場合

| アクション | 費用・金額 |
|---|---|
| 空き地に別荘を建てる | P（500万） |
| 別荘の通行料 | 1.6P（800万） |
| 他人の別荘を**買収してビルに建て替え** | 3P（1,500万） |
| ビルの通行料 | 4P（2,000万） |
| 他人のビルを**買収してランドマーク化** | 8P（4,000万） |
| ランドマークの通行料（着地） | 10P（5,000万） |
| ランドマークの**通過料（素通りでも発生！）** | 6P（3,000万） |

- **買収＝奪って1段階建て替え**。ランドマークになった土地は誰にも買収できない
- **ランドマークは各都市の名物建築**（カイロ=ピラミッド、パリ=エッフェル塔、NY=自由の女神、京都=五重塔…全24種をCSS 3Dで再現）
- **ライン独占**: 同じ色の都市3つを独占すると、そのラインの通行料が2倍

### 特殊マス
| マス | 効果 |
|---|---|
| 🏁 スタート | 通過で給料 3,000G、ぴったり止まるとボーナス +1,000G |
| 🎁 チャンス | カードを1枚引く（ボーナス、罰金、強制移動など全8種） |
| 🏝️ 無人島 | 2回休み。ゾロ目を出せば即脱出！ |
| 🔥 オリンピック | 自分の都市1つを開催地に指定し、通行料2倍（開催地は世界に1つ） |
| ✈️ 世界旅行 | 次のターン、好きなマスへ移動できる |
| 🏛️ 税務署 | 所持金の10%を納税 |

### その他
- ゾロ目を出すともう1回振れる（3連続はスピード違反で無人島行き！）
- 支払いができない場合は安い物件から強制売却され、それでも払えなければ**破産**
